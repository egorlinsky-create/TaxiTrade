## Export Instructions

### Manual (Chrome DevTools)
1. Open the HTML file in Chrome
2. Open DevTools → `Cmd+Shift+P` → "Capture full size screenshot"
3. Each slide/section is exactly the right pixel dimensions
4. Rename files: `appstore-1.png`, `appstore-2.png`, etc.

### Automated (Node.js)
See `export.js` — requires `npm install puppeteer`
```bash
cd store-assets
npm install puppeteer
node export.js
```
Output: `./output/appstore-1.png` … `appstore-5.png` and `playmarket-1.png` … `playmarket-5.png`, `playmarket-feature.png`
